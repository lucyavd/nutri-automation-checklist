# А это точно должна делать ты?

Отдельный интерактивный чек-лист для нутрициологов с клубом, марафоном, групповой программой или мини-курсом.

**Адрес:** https://checklist.avdeeva-ludmila.ru/nutri/

Семь согласованных вопросов с одним ответом на шаг, пять типов результатов, объединяющие гипотезы при нескольких проблемах, дополнительные рекомендации в раскрывающемся блоке, CTA к разработке подходящего цифрового решения через Telegram и ВКонтакте.

## Структура

- src/diagnostic.ts — вопросы/ответы, варианты проблем и рекомендации, приоритет результатов;
- src/App.tsx — семь шагов, главный и дополнительные выводы, возврат к ответам, копирование, контакты;
- tests/diagnostic.test.mjs — тесты опросника и комбинаций;
- tests/e2e.cjs — проверки через Playwright в браузере, предполагает Chrome и playwright-core на сервере;
- deploy/Caddyfile — действующая полная конфигурация маршрутов веб-сервера, включая отдельный /nutri/.

## Разработка

Нужен Node.js 22+. Команды:

    npm ci
    npm run test:unit
    npm run typecheck
    npm run lint
    npm run build

Vite собирает статический сайт для /nutri/, поэтому его нельзя просто открыть с корневого / без настройки base.

## Размещение

- Компьютер: /home/proekt/checklists/nutri-automation
- Сервер: /opt/checklists/nutri-automation
- Публичная ссылка: https://checklist.avdeeva-ludmila.ru/nutri/

Сайт обслуживается отдельным root через handle_path /nutri/*. Основные статические файлы предыдущих чек-листов не менялись.

**Особенность сервера:** у текущего подключённого инструмента нет доступа для записи в /etc/caddy/Caddyfile. Новая конфигурация применена через caddy reload --config /opt/checklists/nutri-automation/Caddyfile.candidate. После системного перезапуска Caddy следует проверить доступность нового маршрута и при необходимости применить сохранённую конфигурацию повторно. В будущем нужно синхронизировать /etc/caddy/Caddyfile через системный доступ администратора. Не заменять конфигурацию только новым блоком: в файле сохранены также все исходные рабочие маршруты.

Контактная форма ничего не отправляет автоматически: человек сам копирует ответы и при желании вставляет их в Telegram или ВКонтакте.

**GitHub:** отдельный удалённый репозиторий ещё не подключён; локальная история Git создана независимо от универсального чек-листа.
